## 🚀 About Me

```yaml
name: Ace
handle: acedev0
location: Global / Remote
primary_focus: Telegram MTProto Automation, Zero-Storage Media Streaming, Distributed Systems
experience: 5+ Years in Telegram platform architecture & bot automation
currently_building: High-performance streaming engines & synchronized real-time web platforms
philosophy: Clean architecture, zero memory bloat, hardened security boundaries
```

- 📡 **Telegram & MTProto Specialist:** 5+ years crafting resilient Telegram bots, userbots, FIFO bulk task runners, and custom MTProto protocol bridges.
- ⚡ **Zero-Storage Streaming Architecture:** Designed systems that stream gigabyte-scale Telegram videos directly to browsers and VLC using HTTP `206 Partial Content` without saving files to disk.
- 🛠️ **DevOps & Production Hardening:** Experienced in unprivileged systemd sandboxes, custom CLI controllers (`aceunzip`, `cinevaultctl`, `televaultctl`), Docker Compose orchestration, and automated installers.
- 🌐 **Modern Full-Stack Engineering:** Building responsive, reactive web applications with **Next.js 15**, **React 19**, **Tailwind CSS**, and **WebSockets**.
