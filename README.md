## `01` — About Me

I'm Ace, an independent developer who enjoys building practical systems that solve demanding technical problems.

My main interests are **Telegram MTProto automation, zero-storage media streaming, production-oriented Python services, and real-time web applications.** I care about what happens beyond the happy path: memory usage, concurrency, failure recovery, security boundaries, and how a system behaves under sustained workloads.

### What I build

- **Telegram infrastructure:** MTProto clients, automated workflows, bulk task processing, progress tracking, and resilient media pipelines.
- **Streaming systems:** HTTP byte-range delivery, `206 Partial Content`, browser and VLC playback, and architectures designed to avoid persistent local media storage.
- **Production tooling:** Linux automation, Docker deployments, systemd services, command-line controllers, and operational tooling.
- **Full-stack applications:** Responsive interfaces, real-time updates, synchronized playback, and API-driven web platforms.

## `03` — Engineering Principles

<table>
  <tr>
    <td align="center" width="25%">
      <h3>⚡</h3>
      <strong>Performance</strong><br />
      <sub>Efficient I/O, asynchronous execution, and controlled concurrency.</sub>
    </td>
    <td align="center" width="25%">
      <h3>🧠</h3>
      <strong>Memory</strong><br />
      <sub>Streaming-first workflows and bounded resource usage where practical.</sub>
    </td>
    <td align="center" width="25%">
      <h3>🛡️</h3>
      <strong>Security</strong><br />
      <sub>Least privilege, safer defaults, and explicit trust boundaries.</sub>
    </td>
    <td align="center" width="25%">
      <h3>🔧</h3>
      <strong>Automation</strong><br />
      <sub>Repeatable deployments, useful logs, and simpler operations.</sub>
    </td>
  </tr>
</table>

I prefer systems that are efficient without becoming unnecessarily complicated. That means using the right concurrency model, avoiding needless disk I/O, handling errors deliberately, and making operational status easy to understand.
